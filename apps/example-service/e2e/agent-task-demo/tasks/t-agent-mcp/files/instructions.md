# Elevation comparison report

You have access to a `geo` MCP service with the tools `mcp__geo__get_elevation`
and `mcp__geo__list_cities`. The figures it returns are the authoritative
source for this task — do not estimate elevations yourself.

Use the geo service to look up the elevations of **Helsinki** and **Tallinn**,
then write a short report (a few sentences) that states:

1. The elevation of Helsinki, in meters.
2. The elevation of Tallinn, in meters.
3. How many meters higher Helsinki is than Tallinn.

Write the report as your final answer. Keep it under 60 words — state the
three numbers plainly, no preamble.
