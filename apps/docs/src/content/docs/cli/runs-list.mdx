## Synopsis

```bash
apo runs list [--task <id>] [--status <s>] [--model <m>] [--effort <e>] [--limit <n>]
```

## Options

| Option | Default | Description |
|---|---|---|
| `--task <id>` | all | Only runs of this task. |
| `--status <s>` | all | Filter by status (`queued`, `running`, `passed`, `failed`, `error`). |
| `--model <m>` | all | Filter by adapter-reported model (repeatable; OR within model). |
| `--effort <e>` | all | Filter by adapter-reported effort (repeatable; OR within effort). |
| `--limit <n>` | backend default | Maximum runs to list. |

`Result` is `PASS` or `FAIL` when a verdict exists, `-` while the run is still going, and `-` for runs that errored or ended with **no verdict**. `Generations` appears as `17/22 error` when model generations ended in error (see [Verdict validity](/concepts/tests/#verdict-validity)); `Cost` is suffixed `partial` when errored generations or unpriced calls were excluded from the total. The `Execution` column shows the adapter-reported model and effort. Pass `--json` for machine-readable output.
