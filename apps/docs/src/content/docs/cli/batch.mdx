## `apo batch show`

Show a batch run's details, aggregate counts, per-task results, costs, and trace ids.

### Synopsis

```bash
apo batch show <batch-id> [--watch]
```

### Options

| Option | Default | Description |
|---|---|---|
| `<batch-id>` | (required) | Batch id or unique prefix. |
| `--watch` | off | Clear the screen and refresh every 3s while the batch is `running` or `queued`. |

## `apo batch list`

List batch runs.

### Synopsis

```bash
apo batch list [--status <s>]
```

### Output

A batch's `Cost` is the sum over its task runs; when any run had unpriced model calls, the total is suffixed `partial`, the same rule as [`apo runs list`](/cli/runs-list/), so an incomplete total never reads as a cheap one.

## `apo batch delete`

Permanently delete a batch run and every task run it owns. For batches that went wrong end to end (infrastructure failure, wrong environment) where deleting run-by-run would be tedious.

### Synopsis

```bash
apo batch delete <batch-id> --yes
```

### Options

| Option | Default | Description |
|---|---|---|
| `<batch-id>` | (required) | Batch id or unique prefix. |
| `--yes` | (required) | Confirms the irreversible delete. Without it, the command prints what would go and exits `2`. |

:::danger[Irreversible]
Deletes the batch, all its task runs (checks, judgments, corrections, deliverables, rows and stored objects, attempts, and traces), and its task revision bundles. There is no undo. Terminal batches only, cancel a live batch first. Requires project admin. Never prompts, so it is safe for agents and CI.
:::
