Evidence expires; verdicts don't. Before an [`APO_EVIDENCE_RETENTION_DAYS`](/self-hosting/data-growth/) window takes a run's checks, traces, and deliverables (or before you delete a run that might matter later) `apo runs export` captures everything the run holds in one versioned JSON file.

:::tip[Bookmark instead for keepers]
If the run should stay inspectable *in apo* rather than in a file, bookmark its trace in the dashboard, bookmarked runs keep every byte of evidence forever, whatever the retention window.
:::

## Synopsis

```bash
apo runs export <run-id> [--out <file>] [--spans]
```

## Description

Takes a **run id** (unique prefix or `last` works, like [`apo runs show`](/cli/runs-show/)) and writes the bundle. Without `--out`, the file lands in the current directory as `run-<id-prefix>-<timestamp>.json`.

The bundle is self-contained, after the run's evidence expires, the file still fully explains it:

| Section | Contents |
|---|---|
| `run` | The full detail projection: verdict, check breakdown (recorded + corrected), transcript, configuration, costs |
| `corrections` | Test-result correction rows with provenance |
| `judgments` | Every judgment incl. its full check evidence |
| `deliverables` | Manifest + inline JSON values + artifact bytes (base64 with sha256) |
| `attempt` | Execution attempt incl. stdout/stderr tails |
| `task_definition_source` | The pinned `*.eval.ts` source the run was scored against |
| `trace` | The trace's calls; add `--spans` for the raw OTel spans (the largest section) |

## Requirements

Project member (same as reading the run). Artifact-heavy bundles can be large, the command allows two minutes for the fetch. Never prompts, so it is safe for agents and CI.

## Exit codes

| Code | Meaning |
|---|---|
| `0` | Bundle written. |
| `2` | Usage error, unknown run, or API failure (incl. an unwritable `--out` path). |

## Examples

```bash
# A failed run worth keeping around before the evidence window takes it
apo runs export last --out regression-evidence/run-$(date +%F).json

# Full fidelity, raw spans included
apo runs export de89cab --spans

# Export first, delete after: the safe order for garbage runs you might revisit
apo runs export de89cab && apo runs delete de89cab --yes
```
