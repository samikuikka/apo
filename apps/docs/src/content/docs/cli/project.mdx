Projects are the authorization and data boundary for Runs, Traces, schedules,
and Task metadata. They do not connect Apo to your repository. Every command
uses the global `--project` flag or the active project saved by `apo login` and
`apo project use`.

## `apo project create`

Create the first project on a fresh instance and mint an API key for it in one call. This is the only legitimate way to bootstrap a project, `apo login` will refuse if your account has no projects yet.

### Synopsis

```bash
apo project create <name> --email <addr> --password <pw> [--scope <full|ingest>] [--backend <url>] [--json]
```

### What it does

1. Verifies your email + password against the backend.
2. Creates a new `ProjectDB` row with a random id and makes you its **owner**.
3. Mints a `full`-scoped API key (shown once) and writes it to `~/.apo/credentials`, so the new project becomes the active one.

Because a real project row is committed before the key is minted, the new strict mint-path check (a nonexistent project id is rejected with `404`) is never an obstacle here.

  lines={[

### Examples

```bash
# First project on a fresh backend
apo project create acme-evals --email me@example.com --password '*****'
```

:::tip[First-run flow]
On a brand-new backend: create the Project, enter your local Task workspace,
run `apo task publish`, then start `apo connect`. The repository stays on your
machine.
:::

## `apo project list`

List projects you can access. The active project is marked with `*`.

### Synopsis

```bash

```

## `apo project use`

Switch the active project. Rewrites `~/.apo/credentials` with the new project id.

### Synopsis

```bash
apo project use [id|name|prefix]
```

With no argument and more than one project, opens an interactive picker. Accepts an id, name, or unique prefix as a positional or via `--project`.

### Output

<TerminalOutput
  lines={[
    { text: "✓ Switched to acme-evals (a1b2c3d4)", tone: "success" },
    { text: "  Run `apo project list` to see all your projects.", tone: "default" },
  ]}
/>

### Examples

```bash
apo project use acme-evals
apo project use staging    # unique prefix
apo project use            # interactive picker
```
