`apo runs judgments` shows the verdict history of a run: the original verdict it ran with, plus every judgment recorded by [`apo runs rejudge`](/cli/runs-rejudge/). The original is always first and always canonical, comparisons start from it, and nothing rewrites it.

## Synopsis

```bash
apo runs judgments <run-id> [judgment-id] [--task <id>]
```

## Arguments

| Argument | Required | Purpose |
|---|---|---|
| `<run-id>` | yes | Run id, unique prefix, or `last`. |
| `[judgment-id]` | no | One judgment's id, show its full test evidence instead of the summary list. |

## Options

| Option | Default | Description |
|---|---|---|
| `--task <id>` | - | Filter `last` to the latest run of a specific task. |

## Example

List every judgment on a run:

```bash
apo runs judgments run_9efafa10f1c3e59647900db5
```

## What the columns mean

| Field | Meaning |
|---|---|
| Trigger | `original`, the run's own verdict, synthesized from its stored evidence. `rejudge`, recorded by `apo runs rejudge`. |
| Judge | The judge model actually used, recovered from stored per-test evidence for the original, from the replay config for rejudges. |
| Checks | Passed / total tests for that judgment. |
| Samples | Judgments made with `--samples n` carry a per-test stability table (`2/5` = passed two of five samples). |
| Revision | Judgments scored against a different definition revision than the run's pinned one say so explicitly, those scores are not comparable to the original verdict. |

Supports the global `--json` flag (the bare judgment array, like `runs list --json`).

## Exit codes

| Code | Meaning |
|---|---|
| `0` | List or judgment detail printed. |
| `2` | Run or judgment not found, or connection failure. |

## See also

- [`apo runs rejudge`](/cli/runs-rejudge/): record a new judgment against a run's stored deliverables.
- [`apo runs correct`](/cli/runs-correct/): record a *human* correction. Judgments stay machine-recorded: correcting a run's test result does not add, change, or promote any judgment listed here, the original entry keeps the counts evaluation emitted.
- [`apo runs show`](/cli/runs-show/): the run's canonical verdict; shows how many judgments are on record.
