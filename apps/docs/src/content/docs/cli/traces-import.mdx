Import one or more session transcripts as traces. Claude Code and Codex already write a full record of every session to disk — this command turns that file into a run in your project, with typed observations, token counts, cost, and tool calls, through the same pipeline natively-traced runs use. See [Import session transcripts](/guides/import-transcripts/) for the workflow this serves.

## Synopsis

```bash
apo traces import <path…> [--source auto|claude-code|codex] [--name <name>] [--tag <tag>…] [--json]
```

## Options

| Option | Default | Description |
|---|---|---|
| `--source <s>` | `auto` | Transcript format. `auto` detects it from the file's content — Claude Code transcripts and Codex rollouts have distinct shapes. |
| `--name <name>` | `<source> session <id>` | The run's label in the runs list. |
| `--tag <tag>` | `transcript-replay`, `<source>` | Run tags, repeatable. |
| `--json` | off | One JSON object per imported file instead of the text summary. |

## Behavior worth knowing

- **Auth** uses your stored login (`apo login`), `--api-key`, or the runner credential env vars — same options as every other command.
- **Imports are idempotent.** The trace id is derived from the session's identity, so importing the same file twice updates the same run instead of duplicating it. Sessions that grew since the last import pick up the new turns.
- **Torn writes don't matter.** Transcripts are appended live; a half-written last line is skipped with a warning, never a failure.
- A file with no completed turns, or a format `--source auto` can't recognize, fails that file and prints why. Other files in the batch still import; the exit code is `1` if any failed.

## Examples

```bash
# Import a Claude Code session picked up from ~/.claude/projects
apo traces import ~/.claude/projects/-home-me-app/2f9c41a8….jsonl

# A Codex rollout, tagged so it's findable later
apo traces import rollout-2026-10-01.jsonl --source codex --tag production

# Several at once, with one label
apo traces import session-a.jsonl session-b.jsonl --name "invoice incident"
```
